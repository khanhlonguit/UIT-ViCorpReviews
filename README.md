<h1 align="center">ViCorpReviews: A Benchmark Dataset for Multi-Dimensional Sentiment and Hate Speech Detection in Vietnamese Workplace Context</h1>

</div>

<p align="center">
  <img src="https://i.postimg.cc/52M5Q8xF/our-pipeline-no-UIT.png" alt="ViCorpReviews" height="40%"/>
</p>

This repository contains the official implementation for **ViCorpReviews** - a novel benchmark dataset curated and annotated for two tasks: Aspect-based Sentiment Analysis (ABSA) and Hate Speech Detection (HSD).

This dataset serves as a foundational benchmark to foster future research in pattern recognition and natural language understanding within the corporate domain in Vietnam.


## Dataset Demo Examples
You can view the demo examples of dataset. The folder contains examples of [Aspect-based Sentiment Analysis (ABSA)](https://github.com/khanhlonguit/ViCorpReviews/tree/main/data-absa-sample) task and [Hate Speech Detection (HSD)](https://github.com/khanhlonguit/ViCorpReviews/tree/main/data-hsd-sample) task.

## How to get the dataset
To download the full dataset, you have to sign the [User Agreement form](https://github.com/khanhlonguit/ViCorpReviews/blob/main/ViCorpReviews_User_Agreement_Form.pdf) and send it to the dataset owner (the email of the owner is in the form).

You will receive the full dataset after you sign and send the User Agreement form.
